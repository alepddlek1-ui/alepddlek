# 네이버 블로그 자동화

관심 있는 단어 하나를 넣으면 **AI 가 요즘 이야기를 훑어 글감을 찾고 → 글을 쓰고 → 사진을 구하거나 그려서
→ 네이버 블로그 글쓰기 화면에 직접 타이핑해 발행까지** 해주는, 내 컴퓨터에서만 도는 앱입니다.

글도 사진도 로그인 정보도 전부 이 컴퓨터의 `data/` 폴더에만 저장됩니다.

---

## 먼저 확인할 것 (30초)

**명령어를 입력하는 창**을 엽니다.
(맥: `Command + 스페이스` → "터미널" 입력 → 엔터 / 윈도우: 시작 → "터미널")

아래를 붙여넣고 엔터를 누릅니다.

```bash
node --version && claude --version
```

숫자 두 줄이 나오면 준비 끝입니다.

- 첫 줄이 없다고 나오면 → https://nodejs.org 에서 **LTS** 를 받아 설치한 뒤 다시 확인합니다.
- 둘째 줄이 없다고 나오면 → `npm install -g @anthropic-ai/claude-code` 로 설치하고 `claude` 를 한 번 실행해 로그인합니다.

> 이 앱은 **Claude 구독요금제**로 돌아갑니다. API 키(종량 과금)를 쓰지 않습니다.

---

## 앱 켜기

```bash
npm install
npm run dev
```

브라우저에서 **http://localhost:4123** 을 엽니다.
검은 배경에 위쪽이 초록색인 화면이 뜨면 성공입니다.

⚠️ 명령어를 입력한 창은 **켜둔 채로** 두세요. 닫으면 앱이 꺼집니다.

---

## 네이버 로그인

글을 대신 올리려면 로그인을 한 번 해두어야 합니다. (보안문자 때문에 자동으로는 못 합니다)

화면 위쪽 **[네이버 로그인]** 을 누르면 새 창이 뜹니다. 평소처럼 로그인하세요.

> **"로그인 상태 유지"에 꼭 체크해 주세요.**
> 안 하면 몇 시간 뒤에 다시 로그인해야 하고, *읽기는 되는데 글쓰기만 막히는* 헷갈리는 상태가 됩니다.

로그인이 끝나면 창이 저절로 닫히고, 화면의 "네이버" 표시에 초록불이 켜집니다.

---

## AI 사진 생성 (선택 — 안 해도 앱은 다 돌아갑니다)

사진을 **AI 가 직접 그리게** 할 수 있습니다. 인터넷에서 가져오는 것보다 저작권 걱정이 없습니다.
안 하셔도 사진을 검색해서 가져오거나, 직접 찍은 사진을 쓰면 됩니다.

```bash
cp env.sample .env.local      # 윈도우: copy env.sample .env.local
```

`.env.local` 을 열어 Cloudflare 계정 ID 와 API 토큰을 채웁니다.
(https://dash.cloudflare.com → Workers AI)

⚠️ **값을 넣은 뒤에는 앱을 껐다 켜야** 반영됩니다.

무료 한도(하루 10,000 뉴런)로 6단계 품질 기준 하루 40장 정도 만들 수 있습니다.

> 나중에 사용량 실측을 보고 싶으면 토큰 권한에 `Account Analytics: Read` 를 추가하세요.
> 대시보드에서 **Edit** 로 고치세요 — **Roll** 은 키를 새로 발급해 `.env.local` 이 무효가 됩니다.

## 처음 써보기

1. 유형을 고릅니다 — **자동 발굴** / **체험단** / **브랜딩·전문성**
2. 주제를 넣고, 사진을 어떻게 할지 고릅니다
3. **[연습으로 만들기]** 를 누릅니다

**연습 모드**라서 실제로 올라가지 않습니다. 3~7분 걸리고, 중간에 브라우저 창이 저절로
열렸다 닫히는데 **건드리지 마세요.** 다 되면 완성된 글과 사진이 화면에 보입니다.

### 진짜로 올리려면

연습으로 만든 글이 마음에 들면, 설정에서 **연습 모드**를 끄면 됩니다.

> **여기서부터는 되돌릴 수 없습니다.** 글이 실제 블로그에 올라갑니다.
> 처음에는 **비공개**로 올려보시길 권합니다 — 기본값이 이미 비공개입니다.
> 나만 볼 수 있어서 어떻게 나오는지 확인하고 나중에 공개로 바꿀 수 있습니다.

---

## 안전장치

| 장치 | 기본값 | 하는 일 |
|---|---|---|
| 연습 모드 | **켜짐** | 발행하지 않고 완성 화면만 저장 |
| 공개 범위 | **비공개** | 발행 직전에 실제로 선택됐는지 확인하고, 확인 안 되면 중단 |
| 전체 중단 | 꺼짐 | 켜면 어떤 작업도 발행되지 않음 |
| 하루 발행 수 | 3편 | 넘으면 발행하지 않음 |
| 최소 발행 간격 | 30분 | 안 지났으면 발행하지 않음 |

이 값들은 설정 화면에서 바꿀 수 있고, 현재 상태는 화면 맨 위와 계량기에 항상 보입니다.

## 꼭 알아두실 것

- **자동 발행은 네이버 이용약관상 계정 제재 위험이 있습니다.** 그래서 연습 모드가 기본값이고
  발행 한도·간격·전체 중단 장치가 있습니다. 편의를 위해 이 장치들을 없애지 마세요.
- 하루 발행 수와 간격은 **네이버가 정한 값이 아니라 이 앱의 자체 브레이크**입니다.
  네이버의 실제 한도는 공개돼 있지 않으니 보수적으로 두는 편이 안전합니다.
- **검색으로 가져온 사진은 저작권 분쟁 소지가 있습니다.** 워터마크·인물 사진을 걸러내지만
  라이선스를 보장하지는 않습니다. 상업적으로 쓰기 전에는 직접 확인하세요.
  그래서 **AI 생성이 더 안전한 선택지**입니다.
- **국내 인물 사진은 초상권 위험**이 있어, 애매하면 빼는 쪽으로 판단합니다.
- 수집한 자료는 **참고용**입니다. 그대로 베끼지 않도록 지시하고, 브랜딩 글에서는
  **실적 숫자를 지어내지 않도록** 합니다.
- 첫 발행은 반드시 **비공개 테스트 글**로 하세요.

그리고 에디터 입력 순서(로컬 하네스)를 한 번에 검사합니다.

## 잘 안 될 때

| 화면에 나오는 말 | 이렇게 하세요 |
|---|---|
| AI 표시에 빨간불 | AI 를 실행하는 프로그램이 아직 없습니다. 위 "먼저 확인할 것"의 설치 안내를 따르세요. |
| 오늘 AI 사용량을 다 썼습니다 | 구독 한도에 걸렸습니다. 몇 시간 뒤 다시 쓸 수 있습니다. |
| 네이버 로그인이 풀렸습니다 | **[네이버 로그인]** 을 한 번 더 누르고, 이번엔 **"로그인 상태 유지"** 를 꼭 체크하세요. |
| 앱이 이미 켜져 있습니다 (`EADDRINUSE :4123`) | 브라우저에서 http://localhost:4123 을 열어보세요. |
| 사진을 AI 로 못 만듭니다 | 열쇠(키)가 필요합니다. 지금은 사진을 **검색해서 가져오기**로 바꾸면 그냥 쓸 수 있습니다. |

### 그 밖에

- `npm run build` 를 한 뒤에 `npm run dev` 가 500 을 내면 `.next` 폴더를 지우고 다시 켜세요.
- 윈도우에서 설치가 실패하면 Node **LTS(짝수 버전)** 로 맞추거나 `npm rebuild better-sqlite3` 를 해보세요.
  (Visual Studio Build Tools 가 필요할 수 있습니다.)
- 브라우저를 자동으로 내려받지 못하는 환경이면 `.env.local` 의 `CHROMIUM_PATH` 에
  이미 깔린 크롬 경로를 적으세요.

## 만든 것들이 어디 있나

```
data/app.db          글·사진·기록이 담긴 데이터베이스
data/images/         내려받거나 만든 사진
data/shots/          발행 직전 화면 스크린샷 (연습 모드의 산출물)
data/session/        네이버 로그인 정보
```

전부 이 컴퓨터 안에만 있습니다. 지우고 싶으면 `data/` 폴더를 통째로 지우면 됩니다.
