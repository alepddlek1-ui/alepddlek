# /learn-style — 문체 학습

대상: $ARGUMENTS

## 절대 규칙 5 — 자동 수집 금지
- **사용자가 직접 제공한 글로만** 갱신한다. 웹을 긁지 않는다
- 네이버 블로그 본문은 **WebFetch가 막혀 있을 수 있다.** 재시도하지 말고 **바로 본문 붙여넣기를 요청**한다
- 남의 글은 분석 대상이 아니다. 본인 글인지 먼저 확인한다

## 절차
1. 글이 제공되지 않았으면 **붙여넣기를 요청한다** (3편 이상이면 정확도가 올라간다)
2. 추출 항목:
   - 자주 쓰는 종결어미 (빈도순 5개)
   - 접속/전환 표현
   - 평균 문장 길이 · 문단 길이
   - 즐겨 쓰는 어휘 / 피하는 표현
   - 제목 패턴 (길이·구조·키워드 위치)
   - 인용구 사용 방식 (몇 개, 어떤 문장을)
   - 도입부 패턴
3. `data/style-profile.md` 를 갱신한다. **분석한 글 목록 표에 날짜·제목·제공 방식을 남긴다**
4. `data/blogger-profile.md` 와 충돌하는 항목이 있으면 **blogger-profile.md가 우선**임을 알리고,
   사용자가 원하면 blogger-profile.md 쪽을 고친다 (임의로 고치지 않는다)
5. 갱신 결과를 요약 보고한다
