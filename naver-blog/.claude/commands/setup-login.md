# /setup-login — 로그인 세션 설정

1. 설치가 안 됐으면 먼저:
```
npm install
npx playwright install chromium
```

2. 로그인 스크립트 실행:
```
node scripts/naver_login.js
```

3. 사용자에게 안내할 것:
- **브라우저 창이 뜨면 직접 로그인한다.** 이 툴은 아이디·비밀번호를 받지도, 저장하지도 않는다
- 2단계 인증·새 기기 등록이 있으면 그것까지 끝낸다
- 로그인이 확인되면 자동으로 글쓰기 페이지 접근까지 검증하고 종료된다
- 세션은 `naver-profile/` 에 저장된다. **외부 공유·커밋 금지** (`.gitignore`에 등록돼 있음)

4. 실패하면:
- 세션 만료 → 다시 실행
- 계속 로그인 화면으로 튕기면 `naver-profile/` 폴더를 지우고 처음부터
- 브라우저가 안 뜨면 `npx playwright install chromium` 재실행

5. 성공 후 안내:
- 브라우저 자동화는 네이버 약관상 회색지대다. **본인 계정으로 하루 1~2건** 권장
