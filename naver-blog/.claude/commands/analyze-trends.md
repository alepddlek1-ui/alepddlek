# /analyze-trends — 트렌드 정리

대상: $ARGUMENTS

## 절대 규칙 5 — 자동 수집 금지
- **사용자가 직접 제공한 자료로만** 갱신한다. 크롤링·자동 수집 금지
- 네이버 블로그·검색 결과는 **WebFetch가 막혀 있을 수 있다.** 재시도하지 말고 **붙여넣기를 요청**한다

## 절차
1. 자료가 없으면 요청한다. 받을 수 있는 것:
   - 상위 노출 글 본문(붙여넣기)
   - 검색어 자동완성·연관검색어 캡처 또는 텍스트
   - 본인 블로그 통계(유입 키워드)
2. 분석:
   - 반복되는 키워드와 **띄어쓰기 형태** (검색어는 띄어쓰기까지 맞춰야 한다)
   - 제목 길이·구조 패턴
   - 도입부 후킹 유형 분포
   - 사진 수·소제목 수·글자 수
   - 스마트블록에 잡힌 글의 공통점
3. `data/trends.md` 갱신:
   - "사용자가 제공한 자료에서 뽑은 트렌드" 섹션에 **출처(어디서 받은 자료인지)와 함께** 누적
   - 후킹 패턴 사용 이력 / 메인 키워드 이력 표는 `/write` 때 채워지는 것이므로 임의로 채우지 않는다
4. 다음 글에 쓸 **키워드 후보 3개**를 근거와 함께 제안한다 (확정은 사용자가)
