# 협찬 표기 문구 (sponsored-disclosure.md)

> 이 블로그의 기본값은 **비협찬**이다. 그래도 `/write`마다 1회 확인한다.
> 협찬이면 **글 상단 첫 블록에 일반 `text` 블록으로** 넣는다 (인용구 아님).
> 업체가 지정한 문구가 있으면 **그 문구가 우선**한다.

## 법적 근거
공정거래위원회 「추천·보증 등에 관한 표시·광고 심사지침」 — **경제적 대가를 받았으면 표기는 생략할 수 없다.**
- 본문과 **같은 크기·색**으로, **글 시작 부분**에
- "체험단", "서포터즈" 같은 말만으로는 부족 — **대가를 받았다는 사실**이 드러나야 한다
- 더보기 접힘·댓글·해시태그에만 넣는 것은 **표기로 인정되지 않는다**

## 대가 유형별 문구

### 1. 제품/서비스 무상 제공
```
이 글은 OOO로부터 제품을 무상으로 제공받아 작성했습니다.
```

### 2. 원고료(현금) 지급
```
이 글은 OOO로부터 원고료를 지급받아 작성한 광고입니다.
```

### 3. 제품 제공 + 원고료
```
이 글은 OOO로부터 제품과 원고료를 제공받아 작성한 광고입니다.
```

### 4. 할인·적립 등 일부 지원
```
이 글은 OOO로부터 체험 비용 일부를 지원받아 작성했습니다.
```

### 5. 수수료(제휴 링크)
```
이 글의 링크를 통해 구매가 발생하면 작성자가 일정액의 수수료를 받습니다.
```

### 6. 대가 없음 (자비 구매 / 자사 소재)
```
(표기 불필요 — 넣지 않는다)
```

## 절대 금지
- 협찬 글에 **"내돈내산"**, **"광고 아님"**, **"대가 없이 작성"** → **거짓 부인은 위법**
- 표기를 접기·흐린 색·작은 글씨로 숨기기
- 대가를 받고 "협찬은 아니지만" 같은 애매한 회피 표현
