# 필수 촬영 컷 가이드 (photo-guide.md)

> 사진 10~15장 · 장당 텍스트 2~4문단.
> **사진은 스토리 순서로 배치한다** (파일 순서 아님).
> 캡션에 키워드 1~2회 — **전체 사진의 절반 정도만**.

---

## 스포츠/연예 이슈 블로그의 대전제
이 주제는 **남의 사진을 쓰기 쉬운 분야**다. 그래서 규칙이 하나 더 붙는다.

```
✔ 쓸 수 있는 사진: 내가 직접 찍은 것 / 사용 권리를 가진 것
✘ 쓸 수 없는 사진: 포털·SNS·기사 캡처, 방송 화면 캡처, 타인 블로그 사진
```
불명확하면 **그 사진을 빼고 글을 쓴다.** 사진 없이도 글은 성립한다.

---

## A. 직관(경기장) 후기 — 필수 컷
```
1. 경기장 외관 + 입구 간판   (장소 특정 · 키워드 노출)
2. 좌석에서 본 시야          (검색자가 제일 궁금해하는 컷)
3. 좌석 번호 / 구역 표지판
4. 전광판 (스코어 · 시간)     ← 날짜·사실의 증거
5. 경기장 내부 먹거리 + 가격표
6. 굿즈샵 / 대기줄 상황
7. 화장실·편의시설 동선
8. 주차장 또는 대중교통 하차 지점
9. 경기 종료 후 전광판 최종 스코어
10. 귀가 동선 (혼잡도)
```

## B. 행사·팬미팅·콘서트 후기 — 필수 컷
```
1. 행사장 외관 + 안내 배너
2. 입장 대기줄 (시간 표시되면 더 좋다)
3. 티켓 / 팔찌 / 입장 표식  ← 개인정보 가림 필수
4. 좌석 시야
5. 공식 포토존 (촬영 허용 구역만)
6. 굿즈 + 가격표
7. 종료 후 혼잡도
```
- **공연 중 촬영이 금지된 행사는 촬영하지 않는다.** 규정 위반 사진은 쓰지 않는다

## C. 장비·자사 소재 (자기 사례)
```
1. 전체 샷
2. 정면 클로즈업
3. 사용 중인 장면
4. 문제/특징이 드러나는 디테일
5. 비교 대상과 나란히
6. 마무리 상태
```
- 서사를 지어내지 않는다. **자기 사례임을 정직하게 밝힌다** (절대 규칙 4)

## 모든 사진 공통 — 촬영 직후 확인
```
✔ 타인 얼굴이 식별되는가        → 모자이크
✔ 차량 번호판이 읽히는가         → 모자이크
✔ 전화번호·주소·명찰이 보이는가   → 모자이크
✔ 티켓의 예매번호·이름이 보이는가 → 모자이크
✔ 화자 본인 얼굴                → 기본 모자이크 (공개 명시 시만 예외)
```
→ 처리는 `scripts/mosaic.js` (원본 절대 보존, 처리본은 `input/photos/_mosaic/`)

## 촬영 팁
- 가로/세로를 섞지 말고 **세로 위주** (모바일 가독성)
- 같은 구도 연속 금지 — 전체 → 중간 → 클로즈업으로 리듬
- **사진 재사용 금지** (유사문서 판정)
- 가능하면 밝은 곳에서, 흔들린 컷은 버린다
