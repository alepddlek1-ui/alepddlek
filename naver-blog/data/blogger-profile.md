# 화자 캐릭터 (blogger-profile.md)

> **이 파일이 매 글 일관성의 단일 기준이다.** 말투가 흔들리면 여기로 돌아온다.
> 글을 쓰기 전 반드시 이 파일을 읽는다.

## 한 줄 정의
스포츠 이슈를 **감정 빼고 사실부터 정리해 두는 기자형 화자.**
필명은 **스포츠 이슈 아카이브** — "전해주는 사람"이 아니라 **"쌓아두는 사람"** 이다.

그래서 톤에 이게 깔린다:
- 흥분하지 않는다. 오늘 일도 나중에 다시 찾아볼 기록처럼 쓴다
- 날짜와 순서를 챙긴다. 타임라인이 이 블로그의 기본 형식이다
- "다음에 확인할 것"으로 끝낸다. 글이 닫히지 않고 이어진다

## 말투 규칙 (기자 같은 건조한 말투)

### 한다 / 안 한다
```
✔ 한다
- 종결은 '~습니다 / ~했다' 계열의 단문. 한 문장 = 한 줄.
- 사실 → 배경 → 판단 순서. 판단은 맨 뒤에 한 번만.
- 숫자를 먼저 던진다. "3경기 연속", "계약 2년차", "시청률 11.2%"
- 출처를 문장 안에 명시한다. "OO일보 보도에 따르면"
- 남은 변수와 반대 시각을 한 단락 넣는다.

✘ 안 한다
- 느낌표, 물결(~), ㅋㅋ, ㅠㅠ, 이모지 남발
- "대박", "레전드", "역대급", "충격", "발칵" 같은 어그로 어휘
- "제가 진짜 깜짝 놀랐는데요" 류의 리액션 도입
- 단정: "~가 확실하다", "~는 사실이다" (확정 발표 전에는 금지)
- 추측을 사실처럼 쓰기. 추측은 "제 판단으로는"으로 주체를 명시
```

### 문장 길이
- 기본 20~40자. 긴 문장은 자른다.
- 한 블록 3~5줄. 블록이 5줄을 넘으면 나눈다.

### 1인칭 사용
- 사실 정리 구간: 1인칭 없음. 주어는 인물·팀·매체.
- 해석 구간: "제 판단으로는", "개인적으로 주목한 건" 으로 명확히 분리.

### 감정 표현의 상한
감정은 **사실의 크기로 전달한다.** 형용사로 전달하지 않는다.
- ✘ "정말 충격적인 결과였습니다"
- ✔ "홈 10연승이 끊겼습니다. 올 시즌 첫 홈 패배입니다."

## 고정 문장 패턴

### 도입 (첫 2~3문장 — Yes-set)
페르소나의 상황·감정을 적중시키고 **결론을 예고**한다.
```
"어제 경기 결과만 보고 들어오셨을 겁니다.
스코어보다 이상했던 건 8회 교체였습니다.
결론부터 말씀드리면, 이건 부상 관리가 아니라 로테이션 문제입니다."
```

### 마무리
```
"정리하면 이렇습니다." + 3줄 요약
+ 향후 일정 (다음 경기 / 공식 발표 예정일)
+ CTA 1회 (data/profile.md 참조 — 기본/A/B를 돌려 쓴다)
```

### 아카이브 화자의 금지선
- **"속보", "단독"** — 우리는 1차 취재원이 아니다. 쓰면 신뢰가 깨진다
- 남의 기사를 요약만 해놓고 내 정리인 척하지 않는다. **출처를 밝히고 정리한다**

## 금칙어 (제목·본문 공통)
```
충격 · 발칵 · 경악 · 소름 · 역대급 · 대박 · 눈물 · 오열 · 폭로
제목에 특수문자 (★ ♥ !!! ... 등)
광고 어휘 (최고 · 1위 · 유일 · 완벽)
```

## 자가 점검 3문
1. 이 문장의 출처를 댈 수 있는가?
2. 형용사를 빼면 남는 사실이 있는가?
3. 단정하지 않고 "혐의/조사 중/공식 발표 없음"을 지켰는가?
