# 트렌드 메모 (trends.md)

> **사용자가 직접 제공한 글·자료로만 갱신한다.** (절대 규칙 5)
> 웹을 자동으로 긁지 않는다. `/analyze-trends`는 사용자가 붙여넣은 자료만 분석한다.

---

## 도입 후킹 패턴 사용 이력
> 직전 글과 같은 패턴을 연속으로 쓰지 않기 위한 기록. `/write`마다 append.

| 날짜 | 글 제목 | 후킹 패턴 | 권위 한 줄 유형 |
|---|---|---|---|
| (비어 있음) | | | |

패턴 종류: `손실 회피형` / `현장 몰입형` / `반전형` / `공감형`

---

## 사용한 메인 키워드 이력
> 같은 키워드를 반복하면 자기 글끼리 경쟁한다(카니발라이제이션).

| 날짜 | 메인 키워드 | 결과(조회수 등) |
|---|---|---|
| (비어 있음) | | |

---

## 사용자가 제공한 자료에서 뽑은 트렌드
> `/analyze-trends` 실행 시 여기에 누적. 출처(어디서 받은 자료인지)를 반드시 같이 적는다.
