# 사용법 (이 파일만 보면 됩니다)

## 완전 자동 (기본)

폴더에서 명령창 열고 **이거 한 줄**이면 끝납니다.

```
auto "https://m.sports.naver.com/기사링크"
```

기사 링크만 주면 이렇게 돕니다:

```
① 브라우저로 기사를 열어 본문을 읽고            (drafts\source-*.txt 로 저장)
② 그 본문만 근거로 글을 쓰고                     (원문에 없는 건 안 씁니다)
③ 정리 이미지 4~6장을 만들고
④ 검증 두 번 — 글쓰기 공식 / 사실 대조
⑤ 네이버에 넣고 임시저장
```

**링크가 안 열리거나 본문이 짧으면 거기서 멈춥니다.** 없는 내용을 지어내지 않으려고 일부러 그렇게 만들었습니다.
그럴 땐 기사 본문을 메모장에 붙여넣어 저장한 뒤:

```
auto 원문.txt
```

끝나면 마지막에 한 줄로 나옵니다:

```
✅ 완료 — 임시저장까지 성공
```
또는
```
❌ 네이버 단계 실패 — (이유)
```

옵션:
```
auto "링크" --dry-run    네이버에 넣되 저장은 안 함 (확인용)
auto "링크" --no-save    네이버 안 건드리고 초안·이미지까지만
auto "링크" --force      하루 2건 한도 무시
```

> 하루 2건까지만 돌아갑니다. 브라우저 자동화는 네이버 약관상 회색지대라 과하게 돌리지 않는 게 안전합니다.

발행은 여전히 **사람이** 합니다. 네이버 "저장 글"에서 어투 손질하고 직접 발행하세요.

## 손으로 하는 순서 (중간에 검수하고 싶을 때)

### 1. 폴더에서 명령창 열기
파일 탐색기로 `naver-blog` 폴더 → 주소창에 `cmd` 치고 엔터

### 2. 최신 버전 받기 (가끔, 수정했다고 알려드릴 때만)
```
update.cmd
```

### 3. 글쓰기 시작
```
claude
```
켜지면 이렇게 칩니다:
```
/write 소재 한 줄 메모

기사 본문:
(기사 본문 복사해서 붙여넣기)

기사 날짜: 2026.09.16
매체: OO일보
사진: 없음 (또는 직접 찍은 것 있음)
협찬: 아님
```

> **기사 본문은 반드시 붙여넣어 주세요.** 링크만 주면 제가 못 엽니다(네이버가 막아둠).
> 캡처 이미지로 주셔도 제가 읽습니다.

### 4. 검수 보고 확인 → 승인
제가 제목·키워드·글자수·체크리스트를 정리해 보고드립니다. 괜찮으면 "진행" 한마디면 됩니다.

### 5. 이미지 만들기 (사진이 없을 때)
```
node scripts\make_cards.js drafts\cards-<이름>.json
```

### 6. 네이버에 넣기
```
node scripts\naver_draft.js drafts\<날짜>-<이름>.json --dry-run
node scripts\naver_draft.js drafts\<날짜>-<이름>.json
```
- `--dry-run` = 저장 안 하고 테스트만 (처음엔 이걸로)
- 두 번째 줄 = 실제 **임시저장** (발행은 코드로 막혀 있어 절대 안 됨)

### 7. 결과 확인
끝나면 나오는 표에서 이 두 줄만 보시면 됩니다:
```
글자수    초안 2087자 → 에디터 2085자 ✔     ← 본문이 다 들어갔는지
전문대조  ✔ 초안과 일치                      ← 내용이 맞는지
```
❗ 표시가 있으면 그 항목만 알려주세요.

### 8. 네이버에서 마무리
- 네이버 블로그 → **저장 글**에 초안이 들어가 있습니다
- **어투 최종 손질은 여기서 직접** 하세요
- 확인 후 **직접 발행** (툴은 절대 발행하지 않습니다)

## 문제가 생기면

실행할 때마다 기록이 이 파일에 저장됩니다:
```
drafts\<초안이름>.log.txt
```
메모장으로 열어서 통째로 복사해 주시면 됩니다. **캡처 안 하셔도 됩니다.**

## 발행할 때 지킬 것

```
✔ 발행 시간대 — 이슈 직후 / 출퇴근 시간 / 심야
✔ 발행 후 24시간은 수정하지 않기
✔ 하루 2~3건까지
✔ 실패한 초안이 "저장 글"에 쌓이면 직접 정리 (툴이 지우지 않습니다)
```

## 하지 말 것

```
✘ 기사 사진·방송 캡처·SNS 사진 쓰기 (저작권)
✘ 출처 없는 사실 쓰기 (제가 막습니다)
✘ naver-profile 폴더 공유하기 (로그인 정보입니다)
```
