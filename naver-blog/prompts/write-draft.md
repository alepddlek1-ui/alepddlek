# 절대 규칙 (어기면 글 전체가 폐기됩니다)
1. **원문에 없는 사실은 한 글자도 쓰지 마십시오.** 기억에 의존한 경기 결과·이적설·배경 설명 금지.
2. **인용구(quote 블록)는 원문에 실제로 있는 문장만** 사용하십시오. 발언을 지어내면 명예훼손이 됩니다.
3. 원문에 없어서 못 쓴 항목은 본문에 "기사에 없어 적지 않았다"고 밝히십시오.
4. 추측과 사실을 문장 단위로 분리하고, 의견은 "제 판단으로는"으로 주체를 밝히십시오.
5. 미확정 사안은 "공식 발표 없음"을, 의혹 보도는 "혐의"·"조사 중" 표현을 유지하십시오.
6. 제목에 특수문자, 그리고 다음 금칙어를 쓰지 마십시오: 충격 발칵 경악 소름 역대급 대박 오열 폭로 속보 단독
7. 외부링크는 넣지 마십시오.

# 글쓰기 공식
- 제목 25~32자. 메인 키워드를 제목 앞쪽에 배치.
- 메인 키워드 1개: 본문에 5~7회, 첫 문단과 마지막 문단에 반드시 포함.
- 서브 키워드 2~3개: 각각 소제목에 배치.
- 첫 문단(3~4줄): 검색해 들어온 사람의 상황을 적중시키고 결론을 예고.
- 둘째 문단(2줄): 권위 한 줄.
- 본문 1,800~2,500자. 한 문장 = 한 줄. text 블록은 2~4줄.
- 인용구 2~4개. 소제목 4~6개. 구분선 1~2개. 이미지 4~6장.
- 이미지·소제목·인용구 없이 텍스트가 400자 넘게 이어지면 안 됩니다.
- 마지막은 정리 3~4줄 + 출처 + 재방문 유도 CTA("스포츠 이슈 아카이브에 쌓아두고 있으니...").
- 태그 6~10개, # 없이.

# 출력 형식 (이것만 출력하십시오. 설명·인사말 금지)
```json
{
  "draft": {
    "title": "",
    "persona": "이 글을 검색해 들어올 사람 한 명을 한 문장으로",
    "mainKeyword": "",
    "subKeywords": ["", "", ""],
    "sponsored": false,
    "fontSize": 16,
    "sources": ["매체명 기자명, 날짜, 기사 제목"],
    "tags": [],
    "blocks": [
      { "type": "text", "text": "한 줄\n한 줄" },
      { "type": "subtitle", "text": "" },
      { "type": "quote", "text": "원문에 실제로 있는 문장" },
      { "type": "divider" },
      { "type": "image", "card": "카드이름", "caption": "선택" }
    ]
  },
  "cards": {
    "size": "square",
    "cards": [
      { "type": "score", "name": "카드이름", "tournament": "", "home": {"name":"","score":0}, "away": {"name":"","score":0}, "meta": ["",""] },
      { "type": "timeline", "name": "카드이름", "title": "", "items": [{"k":"","v":""}], "foot": "선택" },
      { "type": "list", "name": "카드이름", "title": "", "items": [""], "foot": "선택" },
      { "type": "quote", "name": "카드이름", "text": "원문에 있는 문장", "by": "말한 사람" }

```

규칙:
- 이미지 블록의 `card` 값은 cards 배열의 `name` 과 정확히 일치해야 합니다. 파일 경로는 쓰지 마십시오.
- 카드 이름은 영문 소문자와 하이픈만 사용하십시오 (예: goals, timeline, quote, next).
- 카드에 넣는 내용도 원문에서 확인된 것만 쓰십시오.
- 카드 종류는 score / timeline / list / quote 네 가지뿐입니다.
