# TikTok 영어 검색 습관

## 검색어 형태

```
[물건] + [카테고리어]        car vacuum
[장소·행동] + hacks          car cleaning hacks
[계절·대상] + must haves     winter must haves
```

- **2~4단어.** 다섯 단어를 넘기면 결과가 급격히 줄어든다.
- **전부 소문자.** 검색은 대소문자를 구분하지 않고, 해시태그로도 소문자가 표준이다.
- 복수형이 기본이다 — `kitchen gadget`(✗) `kitchen gadgets`(✓).
- `for`, `to`, `the` 같은 기능어를 넣지 않는다. `vacuum for the car`(✗) `car vacuum`(✓).

## 관용어 사전

| 표현 | 뜻 | 쓰는 자리 |
|---|---|---|
| hacks | 꿀팁·요령 | 장소·행동 뒤 — cleaning hacks, car hacks |
| gadgets | 도구·기기 | 카테고리 뒤 — kitchen gadgets |
| must haves | 필수품 | 계절·장소 뒤 — car must haves |
| essentials | 필수품 (조금 더 정보성) | car essentials, winter essentials |
| finds | 발견한 물건 | amazon finds, cheap finds |
| dupes | 저렴한 대체품 (중국어 平替와 같은 뜻) | dyson dupes |
| review / honest review | 후기 | 물건 뒤 |
| unboxing | 언박싱 | 물건 뒤 |
| before and after | 전후 비교 | cleaning before and after |
| satisfying | 보기 좋은 (청소·정리 영상 관용어) | satisfying cleaning |
| organization | 정리·수납 | kitchen organization |
| restock | 채워넣기 (정리 콘텐츠 장르) | fridge restock |
| tiktok made me buy it | 틱톡 보고 샀다 | 단독으로 쓰는 최대 태그 |
| under 20 | 2만 원 아래 | gadgets under 20 |

## 직역하면 안 되는 것들

| 한국어 | 직역 (✗) | 실사용 (✓) |
|---|---|---|
| 차량용 청소기 | vacuum for car use | car vacuum |
| 살림템 | housekeeping items | home gadgets / home finds |
| 주방 꿀템 | kitchen honey item | kitchen gadgets |
| 기름때 제거 | oil dirt removal | degreaser / grease cleaning |
| 정리 용품 | arrangement goods | storage organizers |
| 틈새 청소 | gap cleaning | crevice cleaning |
| 계절 필수품 | seasonal necessity | seasonal must haves |
| 가성비 | cost performance | budget / worth it |
| 육아맘 | childcare mother | mom of a toddler |

## 주의 — 한국에 그대로 안 옮겨지는 각

TikTok 상위 콘텐츠는 미국 주거·생활을 전제로 한다. 다음이 걸리면 각을 바꿔야 한다.

| 전제 | 한국에서 |
|---|---|
| 차고·주차장에서 작업 | 지하주차장·노상. 공간이 좁다 |
| 건조기·식기세척기 기본 | 없는 집이 많다 |
| 대용량·벌크 구매 | 좁은 집엔 안 들어간다 |
| 카펫·마룻바닥 | 장판·타일이 많다 |
| 계절 반대 (남반구 계정) | 업로드 시점이 반대가 된다 |
| 달러 가격대 | 관세·배송비로 국내가는 다르다 |

그대로 베끼지 말고 **구조(훅 순서·보여주는 방식)만** 가져온다.
