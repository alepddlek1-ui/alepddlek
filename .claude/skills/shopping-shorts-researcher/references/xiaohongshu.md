# 샤오홍슈(小红书) 검색 습관

## 어떤 곳인가

물건을 사기 전에 **검색해서 남의 후기를 읽는** 플랫폼이다. 그래서 검색어가 곧 구매 의도다.
주 사용자는 도시의 20~35세 여성이 많고, 집·살림·주방·육아·차량 후기가 두껍게 쌓여 있다.
**우리 채널과 소재가 거의 겹친다.** 여기서 먹힌 각은 한국에서도 먹힐 확률이 높다.

## 검색어 형태

```
[물건] + [관용어]            车载吸尘器 测评
[장소·장면] + [니즈]          厨房 收纳
[대상] + [好物]              宝妈 好物
```

- **3~7자.** 두 단어를 붙인 형태가 가장 흔하다.
- 간체자로 쓴다. 번체(車載)는 대만·홍콩 표기라 결과가 다르게 나온다.
- 문장·물음표로 검색하지 않는다.

## 관용어 사전 (이게 붙으면 쇼핑 후기로 결과가 쏠린다)

| 관용어 | 병음 | 뜻 | 쓰는 자리 |
|---|---|---|---|
| 好物 | haowu | 좋은 물건 | 카테고리 뒤 — 家居好物, 厨房好物 |
| 神器 | shenqi | 신기한 도구, 꿀템 | 고민 뒤 — 收纳神器, 清洁神器 |
| 推荐 | tuijian | 추천 | 카테고리 뒤 — 车载用品推荐 |
| 测评 | ceping | 테스트 후기 | 물건 뒤 — 吸尘器测评 |
| 开箱 | kaixiang | 언박싱 | 물건 뒤 — 开箱视频 |
| 平替 | pingti | 저렴한 대체품 | 비싼 물건 뒤 — 戴森平替 |
| 亲测 | qince | 직접 써봤다 | 앞에 붙임 — 亲测有效 |
| 性价比 | xingjiabi | 가성비 | 앞에 붙임 — 高性价比 |
| 必备 | bibei | 필수품 | 계절·장소 뒤 — 夏日必备, 车内必备 |
| 收纳 | shouna | 정리·수납 | 장소 뒤 — 厨房收纳 |
| 清洁 | qingjie | 청소 | 장소 뒤 — 车内清洁 |
| 懒人 | lanren | 게으른 사람 | 앞에 붙임 — 懒人神器 |
| 一键 | yijian | 원터치 | 앞에 붙임 — 一键搞定 |
| 搞定 | gaoding | 해결하다 | 뒤에 붙임 — 十秒搞定 |

## 대상 지정어 (우리 채널 페르소나와 맞는 것)

| 말 | 병음 | 뜻 |
|---|---|---|
| 宝妈 | baoma | 아기 엄마 (우리 화자와 같은 위치) |
| 新手妈妈 | xinshou mama | 초보 엄마 |
| 上班族 | shangbanzu | 직장인 |
| 学生党 | xueshengdang | 학생층 |
| 租房 | zufang | 세입자·자취 |
| 小户型 | xiaohuxing | 좁은 집 |
| 一人食 | yirenshi | 1인 가구 식생활 |

## 직역하면 안 되는 것들

| 한국어 | 직역 (✗) | 실사용 (✓) |
|---|---|---|
| 차량용 청소기 | 汽车用吸尘机 | 车载吸尘器 |
| 살림템 | 家务物品 | 家居好物 |
| 주방 꿀템 | 厨房蜂蜜物品 | 厨房神器 |
| 기름때 제거 | 油垢除去 | 去油污 |
| 정리 용품 | 整理用品 | 收纳用品 |
| 차 안 먼지 | 车内灰尘 | 车内清洁 |
| 겨울 필수품 | 冬天必要品 | 冬季必备 |
| 아기 이유식 용기 | 婴儿辅食容器 | 辅食盒 |
| 가성비 좋은 | 价格性能好 | 高性价比 |

**차(车)는 车载 로 붙는다** — 车载吸尘器, 车载冰箱, 车载支架. `汽车用` 은 공식 문서체다.

## 결과를 못 믿을 때

- 5자 넘는 조합을 직접 만들었으면 의심한다. 두 덩어리(물건 + 관용어)까지가 안전선이다.
- 브랜드명을 키워드에 넣지 않는다. 우리가 파는 물건이 그 브랜드가 아니고, 검색 결과도 브랜드 팬 콘텐츠로 쏠린다. 예외는 `平替`(대체품)를 찾을 때다 — `戴森平替`(다이슨 대체품)처럼 **비싼 기준 제품 + 平替** 는 실제로 많이 쓰인다.
