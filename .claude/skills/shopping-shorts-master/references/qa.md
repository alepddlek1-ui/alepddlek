# 통합 검수표

각 담당의 체크리스트에서 **부서 밖으로 나가면 안 되는 것**만 추렸다.
담당 체크리스트는 담당이 본다. 마스터는 이 표를 본다.

## 치명 결함 — 하나라도 있으면 승인 불가

| # | 결함 | 어디서 보나 | 누구에게 반려 |
|---|---|---|---|
| 1 | 과장 표현 (최고·1위·완벽·무조건·평생·최저가) | 대본·제목·썸네일·캡션 전부 | 해당 담당 |
| 2 | 협찬·무료 제공·제휴인데 표시 없음 | 대본 첫 3초 · 캡션 첫 줄 | 대본·마케팅 |
| 3 | 낚시 — 제목/썸네일의 궁금증에 대본이 답을 안 함 | 제목 ↔ 대본 | 제목 |
| 4 | 대본에 없는 기능·효과·가격을 캡션이 약속 | 캡션 ↔ 대본 | 마케팅 |
| 5 | 사진·자료에 없는 스펙을 단정 (용량·출력·소재·인증) | 분석·대본·캡션 | 해당 담당 |
| 6 | 분량 위반 — 대본 20초 밖 / 제목 15~20자 밖 | 계산 | 대본·제목 |
| 7 | 정합 깨짐 — 제목·썸네일·첫 자막이 다른 사건 | 네 자리 대조 | 마스터가 조정 |
| 8 | 레퍼런스 문장·자막·음원을 그대로 사용 | 대본·마케팅 | 해당 담당 |
| 9 | 타사 제품 비방 / 가족 얼굴·개인정보 노출 | 대본·화면 메모 | 대본 |

## 경미 결함 — 마스터가 직접 고치고 검수표에 적는다

- 오타·띄어쓰기
- 표 형식 깨짐, 칸 비어 있음
- 파일 경로·파일명 규칙 위반
- 숫자 표기 불일치 (대본은 한글, 자막은 숫자 — 섞였으면 규칙대로 통일)
- 해시태그 순서 (대형 → 중형 → 소형 → 시리즈로 정렬)

## 담당별 통과 조건 요약

| 담당 | 반드시 확인 |
|---|---|
| 리서치 | 중국어 3~7자 간체 · 영어 2~4단어 소문자 · 직역체 없음 · 넓2/중2/좁1 · 국내 대응 검색어 있음 |
| 분석 A | 후킹 8개가 자극3/반전3/사람2 · 근거 칸 전부 채움 · 3차 확장 타겟 있음 |
| 분석 B | 조회수 가설마다 근거 + `재현 가능?` · 20초 비트 초안 있음 · 그대로/바꿀것/버릴것 셋 다 채움 |
| 대본 | 공백 제외 90~105자 · 7~9줄 · 첫 0.3초 동작 · 순서(공감→해결→제품→CTA) · 마지막에 구독+태그+질문 · TTS 규칙(숫자 한글·부호 없음) · brief.yaml 파싱 |
| 제목 | 5개 15~20자 · 서로 다른 궁금증 유형 · 앞 8자 키워드 3개 이상 · 물음표 1개까지 · 썸네일 2줄 분할 · 교체 대기 지정 |
| 마케팅 | 썸네일 3개가 다른 축 · 캡션 유튜브/인스타 분리 · 첫 줄 한 줄 완결 · 저장 장치 1개 이상 · 해시태그 10개 구성비 · 유튜브용 3개 · 대체 텍스트 · 댓글 3개가 한 단어로 답 가능 |
| 소재 | 비슷한 제품 3개의 관계가 서로 다름 · 브랜드·가격 단정 없음 · 연관 5개가 다른 축 · 바로 가능한 것 1개 이상 · 시리즈에 고정 포맷과 1·2·3화 · 배치안 |

## 계산으로 확인하는 것 (눈대중 금지)

```bash
# 1) 대본 공백 제외 자수 — 90~105
python3 -c "
t=open('work/<폴더>/script.txt',encoding='utf-8').read()
n=len(t.replace(' ','').replace('\n',''))
lines=[l for l in t.splitlines() if l.strip()]
print('자수',n,'줄',len(lines),'말하는시간',round(n/5.5,1),'~',round(n/5.0,1),'초')
print([len(l) for l in lines])"

# 2) 제목 자수 — 각 15~20 (공백 포함)
python3 -c "
for l in open('work/<폴더>/titles.txt',encoding='utf-8').read().splitlines():
    if l.strip(): print(len(l), 'OK' if 15<=len(l)<=20 else '**범위밖**', l)"

# 3) 브리프 파싱 — 필드 오타를 여기서 잡는다
python3 -c "
from reelforge.script.brief import load_brief
b=load_brief('work/<폴더>/brief.yaml')
print('OK', b.project, b.size, b.captions.source, b.narration.enabled)"
```

세 개를 돌려보지 않고 통과시키면, 촬영이 끝난 뒤에 분량이 안 맞는 걸 알게 된다.

