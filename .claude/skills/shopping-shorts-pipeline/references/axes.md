# 일곱 개 확장 축

소재는 짜내는 게 아니라 **굴리는 것**이다. 상품 하나를 일곱 축에 넣고 질문만 하면 소재가 나온다.
축 하나에 소재 3개씩이면 상품 하나로 **21편**이다.

---

## 1. 제품 축 — 옆에 있는 물건

**질문**: 같은 고민을 다르게 푸는 물건은? 이것과 같이 쓰는 물건은? 더 싼 것 / 더 비싼 것은?

| 관계 | 뜻 | 예 (차량용 청소기) |
|---|---|---|
| 같은 고민 다른 방식 | 목적은 같고 방법이 다르다 | 틈새 브러시, 에어 블로워 |
| 가격대 아래 | 더 싸게 해결 | 실리콘 틈 막이 (애초에 안 들어가게) |
| 가격대 위 | 제대로 해결 | 유선 대용량 차량 청소기 |
| 같이 쓰는 것 | 세트로 쓰인다 | 차량용 쓰레기통, 매트 |
| 같은 자리 다른 물건 | 자리가 같다 | 컵홀더 정리함, 컵홀더 코스터 |

**주의**: 브랜드·모델·가격을 단정하지 않는다. 제품 유형과 검색어까지만.

---

## 2. 장면 축 — 같은 물건, 다른 자리

**질문**: 이걸 집 어디서 또 쓸 수 있나? 차에서? 캠핑에서? 사무실에서?

"의외의 용도"는 훅 공식 중에서도 강한 편이다. **새 물건을 안 사고 편수를 늘리는 가장 싼 방법**이기도 하다.

| 자리 | 소재 |
|---|---|
| 집 | 소파 틈, 책상 밑, 창틀, 키보드, 서랍 |
| 차 | 시트 틈, 컵홀더, 매트, 트렁크, 대시보드 |
| 밖 | 캠핑, 유모차, 가방 안, 사무실 |
| 계절 | 여름 모래·풀, 겨울 눈·염화칼슘 |

---

## 3. 사람 축 — 가족 고정 캐릭터

**질문**: 이걸 우리 가족 누구에게 주면 이야기가 되나?

가족 7인은 각자 역할이 정해져 있다 (`../shopping-shorts-writer/references/persona.md`).
같은 물건이 **누구 손에 가는가**로 편이 갈린다.

| 인물 | 이 물건으로 만들 수 있는 편 |
|---|---|
| 남편 | 자기 차에 가져갔다 → 남녀 공용 증명 |
| 친정엄마 | 하나 더 사달랬다 → 중장년까지 통하는 증명 |
| 여동생 | 그냥 들고 갔다 → 20대도 쓴다 |
| 오빠 | 스펙 따져 물었다 → 반론 죽이기 편 |
| 이모 | 세 개 사갔다 → 대량·선물용 |
| 삼촌 | 뜯어봤다 → 테크·차량 검증 |
| 아기 | 부수거나 엎었다 → 내구성·난이도 증명 |

---

## 4. 시간 축 — 나중에 다시

**질문**: 한 달 뒤엔 어떤가? 세 달 뒤엔? 계절이 바뀌면?

**이미 올린 편을 재활용하는 축**이다. 새 소재가 필요 없다.

- 일주일 후기 / 한 달 후기 / **세 달 후기** (가장 신뢰가 높다)
- 고장·마모 보고 ("삼 개월 썼더니 여기가")
- 계절이 바뀐 뒤 같은 물건 ("여름엔 이렇게 쓰네요")
- 재구매 여부 ("또 살까요? 결론부터")
- 작년에 산 것 정리 ("올해 제일 잘 산 것 세 개")

---

## 5. 실패 축 — 안 좋았던 것

**질문**: 이거 쓰기 전에 뭘 실패했나? 이것의 단점은? 반품한 건 뭔가?

**가장 신뢰를 많이 얻는 축이고, 가장 안 쓰는 축이다.** 잘 쓰면 채널 색이 된다.

- 전에 산 비싼 것과 비교 ("오만 원짜리 버리고 이거 씁니다")
- 이 물건의 단점 ("이건 좀 아쉬워요") — 단점을 말하면 나머지 말이 믿긴다
- 세 번 실패한 이야기
- 반품한 것과 그 이유
- 안 사도 되는 것 ("이건 없어도 됩니다")

과장 금지선과 정직함이 여기서 채널 자산으로 바뀐다.

---

## 6. 고민 축 — 같은 자리의 다른 짜증

**질문**: 이 자리에서 또 짜증나는 건 뭐가 있나?

물건이 아니라 **자리와 고민**을 기준으로 뻗는 축이다. 검색 수요가 확실하다.

| 자리 | 다른 고민들 |
|---|---|
| 차 안 | 컵홀더 끈적임, 냄새, 서리, 매트 모래, 선 정리 |
| 주방 | 기름때, 배수구 냄새, 밀폐용기 뚜껑, 냉장고 정리 |
| 욕실 | 물때, 곰팡이, 배수구 머리카락, 수건 |
| 현관 | 신발 냄새, 먼지, 우산 |

---

## 7. 형식 축 — 같은 소재, 다른 그릇

**질문**: 이 이야기를 다른 형식으로 한 번 더?

같은 제품·같은 고민이라도 형식을 바꾸면 다른 영상이 된다.

| 형식 | 내용 | 강점 |
|---|---|---|
| 전후 비교 | 같은 앵글 before/after | 대비가 가장 셈 |
| 목록형 | "차에 두면 편한 것 세 개" | 저장이 잘 됨 |
| 비교 테스트 | 싼 것 vs 비싼 것 | 판단 궁금증 |
| 질문 답변 | 댓글 질문에 답하기 | 참여가 이어짐 |
| 실시간 | 사서 바로 뜯기 | 현장감 |
| 정리·루틴 | 한 주에 한 번 하는 것 | 반복 시청 |
| 남편 시험 | 가족에게 몰래 써보게 | 이 채널만의 형식 |

**댓글에서 나온 질문은 형식 축의 무료 소재다.** 고정 댓글에 달린 질문을 다음 편 소재로 쓴다.

---

## 소재가 떨어졌다고 느낄 때

1. 최근 5편이 어느 축에서 나왔는지 적어본다. 대개 한두 축에 쏠려 있다.
2. **안 쓴 축**을 고른다. 특히 5번 실패 축과 4번 시간 축이 비어 있을 것이다.
3. 그 축의 질문을 지금 상품에 그대로 던진다.
4. 그래도 안 나오면 **고민 축**으로 간다. 물건은 떨어져도 짜증은 안 떨어진다.
