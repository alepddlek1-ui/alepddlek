# 시리즈 설계

## 시리즈가 단발보다 강한 이유

- 같은 코너를 본 사람이 **다음 편에서 돌아온다** (재방문 시청자)
- 고정 해시태그에 편이 쌓여 **그 태그가 검색 결과가 된다**
- 기획이 반복되니 **찍는 시간이 줄어든다** (포맷이 정해져 있다)
- 채널이 무슨 채널인지 한 줄로 설명된다

## 시리즈에 반드시 있어야 하는 네 가지

| 고정 요소 | 뜻 | 예 |
|---|---|---|
| **오프닝 동작** | 매 편 같은 첫 0.3초 | 물건을 툭 내려놓기 |
| **제목 형태** | 틀이 같고 단어만 바뀜 | `삼천 원으로 해결한 OOO` |
| **자막 형태** | 같은 위치·같은 강조색 | 가격을 노란색으로 |
| **마무리 질문** | 같은 형태의 댓글 유도 | `다음엔 뭐 써볼까요?` |

네 개 중 **셋 이상 고정**되면 시청자가 코너로 인식한다. 매번 바꾸면 그냥 단발 영상 모음이다.

## 이미 쓰는 고정 코너

| 코너명 | 포맷 | 고정 해시태그 | 소재 축 |
|---|---|---|---|
| **삼천 원 살림템** | 저가 생활용품 하나, 가격을 먼저 말하기 | `#삼천원살림템` | 제품·고민 |
| **남편이 훔쳐간 물건** | 내가 산 걸 남편이 가져간 이야기 | `#남편이훔쳐간물건` | 사람 |
| **엄마가 하나 더 사달랬어요** | 친정엄마 검증 통과한 물건 | `#엄마가하나더사달랬어요` | 사람 |
| **차에 두면 편한 것** | 차 안 한 자리씩 | `#차에두면편한것` | 장면·고민 |
| **계절 미리 준비** | 2주 앞서 꺼내기 | `#계절미리준비` | 시간 |
| **사자마자 후회한 것** | 실패 자백, 단점부터 | (신규) | 실패 |
| **아기가 부순 것, 안 부순 것** | 내구성 증명 | (신규) | 사람·시간 |

**새 코너를 만들기 전에 기존 코너에 붙일 수 있는지 먼저 본다.** 코너가 일곱 개를 넘으면 시청자가 못 따라온다.

## 새 코너를 제안할 때 적는 것

```
코너명     — 한 번에 이해되는 다섯 자 내외
고정 포맷  — 오프닝 동작 / 제목 형태 / 자막 형태 / 마무리 질문 중 셋 이상
1·2·3화    — 실제로 찍을 수 있는 소재 세 개 (하나는 지금 바로)
몇 편까지  — 정직하게. 소재가 몇 개 있는지 세보고 쓴다
해시태그   — 바꾸지 않을 하나
```

## 몇 편까지 가는지 세는 법

코너 하나의 수명은 **소재 개수 ÷ 업로드 빈도**다.

| 수명 | 판정 | 쓰는 법 |
|---|---|---|
| 3편 이하 | 시리즈 아님 | 단발로 올린다. 코너 이름을 붙이지 않는다 |
| 5~10편 | 미니 코너 | 두 달 정도 굴리고 접는다. 접는 것도 계획에 넣는다 |
| 20편 이상 | 본 코너 | 고정 해시태그를 만든다. 채널 대표 코너로 키운다 |

**소재가 무한한 코너의 조건**: 고민 축이나 장면 축에 걸려 있어야 한다.
`차에 두면 편한 것` 은 차 안 자리가 계속 나오니 오래 가고, `이 브랜드 신제품` 은 브랜드가 안 내면 끝난다.

## 시리즈가 죽는 이유

| 이유 | 막는 법 |
|---|---|
| 포맷을 매번 바꿈 | 네 가지 고정 요소 중 셋을 지킨다 |
| 소재를 세어보지 않고 시작 | 시작 전에 1·2·3화를 확보한다 |
| 같은 코너를 연달아 올림 | 코너를 돌려가며 배치한다 |
| 반응 없는데 계속 끌고 감 | 5편까지 반응 없으면 접는다. 접는 게 실패가 아니다 |
| 코너가 너무 많음 | 동시에 굴리는 코너는 세 개까지 |
| 해시태그를 바꿈 | 쌓인 게 흩어진다. 절대 바꾸지 않는다 |
