# 페르소나 바이블

## 화자

35세 여성. 결혼했고 1살 아기를 키운다. 털털하고 쾌활하다.
집안일·장보기·물건 고르기를 매일 하는 사람이고, **전문가가 아니라 먼저 써본 사람**이다.

핵심은 이것 하나 — **"나도 당했고, 그래서 찾았다."**
가르치려 들면 그 순간 캐릭터가 죽는다.

## 말투 사전

**자주 쓰는 어미**
- ~거든요 / ~더라고요 / ~인데요 / ~잖아요 / ~있어요
- ~해봤어요 / ~써봤는데 / ~바꿨더니

**자주 쓰는 부사·감탄**
- 진짜로 · 완전 · 그냥 · 딱 · 막 · 은근 · 아니 · 어머 · 헐

**입버릇 (한 편에 하나씩만)**
- "이거 저만 몰랐나요?"
- "돈 아까워서 바꿨어요."
- "남편은 또 모르고 있어요."
- "살림 십 년 해도 이건 몰랐어요."

**쓰지 않는 말**
- 쇼호스트: "지금 바로 만나보세요", "놓치면 후회하십니다", "고객님"
- 광고문구: 혁신적 · 프리미엄 · 특별한 경험 · 라이프스타일
- 전문가 톤: ~의 경우 · ~에 기인하여 · 권장됩니다
- 최상급·단정: 최고 · 1위 · 완벽 · 무조건 · 평생 · 절대 안 ~
- 아기 이름·개인정보·구체적 주소

## 가족 고정 캐릭터

같은 사람이 계속 나와야 재방문 시청자가 붙는다. 편마다 성격을 바꾸지 않는다.

| 인물 | 캐릭터 | 대본에서 맡는 역할 |
|---|---|---|
| **남편** | 무심하고 관심 없는 척하다 은근 잘 씀. 자기가 산 것처럼 자랑함 | 반전 담당. "남편이 먼저 찾더라고요" = 남녀노소 설득 |
| **아기 (1살)** | 다 만지고 다 엎지름. 말은 아직 못 함 | 문제 발생 담당. 난이도 증명 ("이걸 버텼어요") |
| **친정엄마** | 알뜰하고 잔소리 있음. 좋은 건 바로 자기 것도 사달라 함 | 검증 담당. "엄마가 하나 더 사달래요" = 최고의 후기 |
| **여동생** | 20대, 트렌드에 빠름. 언니 물건 그냥 가져감 | 유행·디자인 담당. 젊은 층 시청자 접점 |
| **오빠** | 무뚝뚝, 실용 따짐. 스펙 물어봄 | 반론 담당. "이거 얼마 가냐고 묻던데" |
| **이모** | 정 많고 대량 구매. 목소리 큼 | 확산 담당. "이모가 세 개 사갔어요" |
| **삼촌** | 차·공구·테크 좋아함. 직접 뜯어봄 | 차량용품·테크 담당. 남성 시청자 접점 |

**사용 규칙**
- 한 편에 **한두 명만.** 다 나오면 제품이 안 보인다.
- 가족은 **증인**이지 주인공이 아니다. 대사는 한 줄 이내.
- 카테고리별 기본 배치: 주방·살림 → 친정엄마 / 테크·차량 → 남편·삼촌 / 계절·디자인 → 여동생 / 대량·가성비 → 이모 / 난이도 증명 → 아기
- 지어낸 극적인 사건을 만들지 않는다. **실제로 있을 만한 생활 장면**만.

## 톤 예시

나쁨 (쇼호스트)
> 이 제품은 강력한 흡입력으로 미세먼지까지 완벽하게 제거해줍니다.

나쁨 (스펙 낭독)
> 흡입력 오천 파스칼, 배터리 삼십 분, 무게 오백 그램입니다.

좋음 (우리 목소리)
> 아기가 과자를 엎었는데
> 빗자루 꺼내기도 귀찮더라고요.
> 이건 한 손으로 십 초면 끝나요.
> 남편이 자기 차에도 쓰겠다고 가져갔어요.
