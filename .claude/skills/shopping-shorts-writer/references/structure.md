# 20초 구조

## 비트 표 (기본형)

순서는 고정이다 — **공감/문제 → 해결 → 제품 → CTA.**

| 초 | 비트 | 하는 일 | 화면 | 분량 |
|---|---|---|---|---|
| 0.0~1.0 | **훅** | 결론·사건을 먼저 던진다. 과감한 동작 + 큰 자막 | 움직임이 있는 클로즈업 | 1줄 (8~14자) |
| 1.0~4.0 | **공감/문제** | 누구나 겪는 그 짜증. 가족 한 명 등장 가능 | 문제 상황 실사 | 2줄 |
| 4.0~8.0 | **해결** | "이렇게 했어요" — 해결 동작을 보여준다. 제품 실물 등장 (4초 안) | 손이 제품을 쓰는 컷 | 2줄 |
| 8.0~14.0 | **제품** | 왜 되는지 한 가지 + 숫자 + 반론 하나 죽이기 | 클로즈업 2~3컷 | 2~3줄 |
| 14.0~17.5 | **증인/오픈 루프** | 가족 반응 한 줄, 또는 안 풀어준 한 가지 | 가족 손·반응 | 1줄 |
| 17.5~20.0 | **CTA + 구독 + 댓글** | 제품 태그 유도 + 구독 요청 + 되묻는 질문 | 제품 + 태그 가리키는 손 | 1~2줄 |

합계 **7~9줄 · 공백 제외 90~105자.**

## 화면 전환

2~3초마다 바뀐다. 20초면 **7~9컷.**
같은 앵글을 3초 넘게 두면 이탈한다. 말이 이어지더라도 앵글은 바꾼다.

권장 컷 리듬: 클로즈업 → 손 동작 → 전체 → 클로즈업 → 결과 → 가족 → 제품+태그

## 마지막 2.5초 설계 (참여도가 여기서 결정된다)

세 가지를 한 호흡에 넣는다. 길어지면 안 되니까 **각각 한 마디씩.**

1. 제품 태그 — "아래 노란 장바구니에 걸어뒀어요."
2. 구독 — "같은 살림템 계속 올릴게요. 구독 눌러주세요."
3. 댓글 질문 — "이거 남편 줄까요, 제가 쓸까요?"

댓글 질문 만드는 법 (답이 한 단어로 나와야 달린다)
- 양자택일: "주방에 둘까요, 차에 둘까요?"
- 경험 소환: "이거 저만 몰랐어요?"
- 숫자 맞히기: "이거 얼마일 것 같아요?"
- 추천 요청: "다음엔 뭐 써볼까요?"

## 루프 만들기

마지막 화면이 **첫 화면과 같은 구도**면 시청자는 한 번 더 본다.
훅에서 "쏟는 장면"으로 시작했으면, 끝도 "깨끗해진 같은 자리"로 닫는다.

## 오픈 루프 배치

결론은 1초에 다 깐다. 대신 **하나는 끝까지 안 준다.**
- "제일 좋은 기능은 따로 있는데 그건 댓글에 적어둘게요."
- "이거 원래 용도 아닌데, 저는 여기다 씁니다." (용도를 끝에 딱 한 번만 보여준다)

## 고정 코너 (시리즈로 굴리기)

대본을 낼 때마다 같은 코너의 다음 3편 제목을 덧붙인다.

- **삼천 원 살림템** — 저가 생활용품 한 개
- **남편이 훔쳐간 물건** — 남녀 공용 증명 (테크·차량)
- **엄마가 하나 더 사달랬어요** — 중장년까지 통하는 물건
- **사자마자 후회한 것 / 두 개 산 것** — 솔직 후기 2연작
- **계절 미리 준비** — 2주 앞서 꺼내는 계절상품
- **주방 십 초 정리** — 주방용품 루틴
- **차에 두면 편한 것** — 차량용품
- **아기가 부순 것, 안 부순 것** — 내구성 테스트
