# 검색 키워드 · 해시태그 설계

## 사람들은 제품명으로 검색하지 않는다

제품명을 아는 사람은 이미 살 사람이고, 수가 적다.
**모르는 사람이 치는 말**은 고민과 상황이다.

| 안 걸리는 말 | 실제로 치는 말 |
|---|---|
| 고광택 코팅제 | 차 유리 물때 제거 |
| 다용도 실리콘 트레이 | 이유식 소분 용기 |
| 무선 진공 클리너 | 차 시트 틈 청소 |
| 기능성 방한 용품 | 발 시려움 |

## 검색어 조합 공식

```
[카테고리] + [상황/장소] + [고민] + (대상)
```

- 주방용품 + 가스레인지 + 기름때 → **가스레인지 기름때**
- 차량용품 + 시트 틈 + 부스러기 → **차 시트 틈 청소**
- 계절상품 + 장마 + 빨래 냄새 → **장마철 빨래 냄새**
- 살림템 + 냉장고 + 정리 + 자취 → **자취방 냉장고 정리**

만들고 나서 스스로 확인한다 — **내가 이 말을 검색창에 칠까?** 아니면 버린다.

## 키워드 세 층으로 나눈다

| 층 | 성격 | 쓰는 자리 | 개수 |
|---|---|---|---|
| **주 키워드** | 카테고리 + 고민. 검색량 있음 | 제목 앞쪽 · 캡션 첫 줄 · 첫 자막 | 1개 |
| **보조 키워드** | 상황·장소·대상으로 좁힌 것 | 캡션 본문 문장 안 | 2~3개 |
| **연관어** | 같은 뜻 다른 말 (오타·구어 포함) | 캡션 끝·해시태그 | 2~3개 |

세 곳(제목·캡션 첫 줄·첫 자막)에 **같은 뜻을 심는다.** 같은 문장을 복사하는 게 아니다.

## 해시태그 10개 구성

| 층 | 개수 | 성격 | 예시 |
|---|---|---|---|
| **대형** | 2 | 카테고리 전체. 노출은 넓고 경쟁은 심함 | #살림템 #주방용품 |
| **중형** | 4 | 카테고리 + 상황. 실제 유입이 나오는 층 | #차량용품 #차청소 #기름때제거 #자동차용품추천 |
| **소형·니치** | 3 | 고민을 콕 찍은 말. 적게 보지만 정확히 산다 | #시트틈청소 #아기있는차 #과자부스러기 |
| **시리즈** | 1 | 우리 채널 고정 태그. 쌓이면 그 자체가 코너가 된다 | #삼천원살림템 |

**규칙**
- 대형만 10개 = 묻힌다. 소형만 10개 = 아무도 안 본다. 섞어야 한다.
- 영상에 없는 주제의 태그를 넣지 않는다.
- 한글 태그를 우선한다. 이 채널 시청자는 한글로 검색한다.
- **유튜브에는 3개만.** 쇼츠 설명에 태그를 많이 달면 제목 위에 표시되며 지저분해지고 효과도 흐려진다. 10개 중 대형 1 + 중형 1 + 시리즈 1을 골라 따로 표시한다.
- 인스타는 10개를 캡션 **본문 끝**에 붙인다. 첫 댓글로 숨기지 않는다.
- 시리즈 태그는 절대 바꾸지 않는다. 바꾸면 쌓인 게 흩어진다.

## 시리즈 태그 목록 (고정)

- `#삼천원살림템` — 저가 생활용품
- `#남편이훔쳐간물건` — 남녀 공용 증명
- `#엄마가하나더사달랬어요` — 중장년까지 통하는 물건
- `#차에두면편한것` — 차량용품
- `#계절미리준비` — 계절상품

## 계절·시점 캘린더 (계절상품은 2주 앞서 올린다)

| 시기 | 걸리는 검색어 |
|---|---|
| 2~3월 | 황사·미세먼지, 봄맞이 대청소, 환절기 건조 |
| 5~6월 | 장마 대비, 곰팡이, 빨래 냄새, 제습 |
| 7~8월 | 차 안 더위, 선풍기·서큘레이터, 벌레, 물놀이 |
| 9~10월 | 환절기, 나들이·캠핑, 차 유리 서리 |
| 11~12월 | 김장, 난방비, 결로, 발 시려움, 연말 선물 |
| 1~2월 | 정리·수납, 새 학기 준비, 설 선물 |
