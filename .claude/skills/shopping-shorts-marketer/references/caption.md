# 캡션 서식

유튜브와 인스타는 읽히는 방식이 달라서 같은 캡션을 쓰면 둘 다 손해다. **따로 쓴다.**

## 유튜브 쇼츠

```
제목: [주 키워드] + [결과·숫자]          ← 40자 이내, 키워드를 앞쪽에

설명:
1줄 - 영상 내용 한 줄 요약 (주 키워드 그대로 들어간다)
2줄 - 보조 키워드를 문장 안에 녹인 한 줄
3줄 - 정보 한 줄 (가격·크기·쓰는 자리 — 지금 기준이라고 밝힌다)
4줄 - 제품 태그 안내 + 구독 한 줄
태그 3개
```

- **제목이 제일 중요하다.** 검색과 추천에 같이 쓰인다. 키워드는 앞쪽, 결과는 뒤쪽.
- 제목에 이모지·괄호·대괄호를 쓰지 않는다. 글자만.
- 설명 **첫 1~2줄만** 펼치기 전에 보인다. 중요한 것은 거기서 끝낸다.
- 해시태그는 **3개까지.** 많이 달면 제목 위에 줄줄이 붙어 지저분하고 효과도 흐려진다.
- 쇼핑 제품 태그를 쓰면 설명 첫 줄에 수수료 여부를 밝힌다.
- 고정 댓글 한 줄을 같이 낸다. 댓글 유도 질문 + 가격 정정용으로 쓴다.

## 인스타 릴스

```
1줄 - 훅. 펼치기 전에 다 읽히게 한 줄로 끝낸다 (주 키워드 포함)
(빈 줄)
본문 3~4줄 - 상황 → 해결 → 정보 (한 줄에 한 문장, 짧게)
(빈 줄)
저장 유도 한 줄
해시태그 10개
대체 텍스트: 화면을 글로 설명한 한 줄
```

- **첫 줄이 전부다.** 나머지는 펼쳐야 보인다. 첫 줄에 키워드와 결과를 같이 넣는다.
- 줄바꿈으로 숨을 준다. 한 덩어리로 붙여 쓰면 아무도 안 읽는다.
- 인스타도 키워드로 검색된다. **캡션 문장 안에 키워드를 녹인다** (태그에만 두지 않는다).
- 해시태그 10개는 본문 끝에. 첫 댓글로 숨기지 않는다.
- **대체 텍스트**를 꼭 채운다. 화면을 못 보는 사람에게 전달되고, 검색에도 읽힌다.
  예: `차 시트 틈에서 과자 부스러기를 미니 무선청소기로 빨아들이는 손`

## 저장을 만드는 장치 (하나 이상 필수)

| 장치 | 쓰는 법 | 문장 예시 |
|---|---|---|
| **정보** | 가격·크기·용량·색상·쓰는 자리를 적는다 | 컵홀더에 들어가요. 지금 기준 만 구천구백 원이에요. |
| **목록·기준** | 고를 때 볼 것을 번호로 | 살 때 이것만 보세요. 첫째 무게, 둘째 충전 방식. |
| **시점** | 언제 필요한지 못박는다 | 장마 시작하기 전에 사두는 게 낫더라고요. |
| **부탁** | 말로 시킨다. 안 시키면 안 누른다 | 필요할 때 못 찾아요. 저장해두세요. |

**부탁은 마지막 한 줄에 한 번만.** 두 번 쓰면 광고가 된다.

## 대가를 받았으면 첫 줄에

- 유료광고·협찬·무료 제공·제휴 수수료 중 하나라도 해당되면 **캡션 첫 줄**에 밝힌다. 끝에 붙이면 못 본 사람이 생긴다.
- 문구: `유료 광고 포함` · `제품 무료로 받았어요` · `제휴 링크 수수료 받아요`
- 유튜브 업로드 설정의 **유료 프로모션 포함** 체크도 같이 안내한다.
- 내 돈으로 산 것이면 그것도 쓴다. 이 채널에서는 그게 제일 센 문장이다.

## 캡션에서 하지 말 것

- 키워드 나열 (검색에 도움 안 되고 읽는 사람이 먼저 떠난다)
- 영상에 없는 기능·효과를 캡션에서 새로 약속하기
- 최저가·최고·1위·완벽·무조건 → `../shopping-shorts-writer/references/compliance.md`
- 링크를 본문 중간에 끼워넣기 (인스타는 본문 링크가 안 눌린다. 프로필로 안내한다)
- 같은 캡션을 두 플랫폼에 복사
