# 완성 예시 (출력 4블록)

`shopping-shorts-writer/references/example.md` 의 대본(차량용 미니 무선청소기 · 19,900원 ·
컵홀더에 들어가는 크기)을 그대로 받았다고 가정한 견본이다. 형식·분량의 기준선으로 쓴다.

---

**① 썸네일 문구 3개**

1. (추천) **시트 틈 십 초에** — 숫자 먼저 + 검색어("시트 틈")를 커버에 박았다. 그리드에서도 9자라 다 읽힌다.
2. **남편이 가져갔어요** — 사람축. 육아맘 채널 영상이 남성 시청자에게도 밀린다.
3. **주방템인데 차에서** — 반전축. 용도가 뻔해 보이는 물건일 때 클릭을 만든다.

커버 프레임: 시트 틈에 청소기를 대고 **손이 나온 컷.** 문구는 화면 위쪽 3분의 1, 흰 글씨 + 검정 외곽선, "십 초" 만 노란색.

**② 검색 최적화 캡션**

▸ 유튜브 쇼츠

```
제목: 차 시트 틈 과자 부스러기, 십 초에 끝냈어요

설명:
차 시트 틈에 들어간 과자 부스러기, 손도 안 들어가서 포기하고 있었어요.
컵홀더에 들어가는 미니 무선청소기로 십 초에 정리했고 삼 개월째 쓰고 있어요.
크기는 컵홀더에 쏙 들어가고 지금 기준 만 구천구백 원이에요. (가격은 바뀔 수 있어요)
제품은 아래 태그에 걸어뒀어요. 같은 차량용품 계속 올릴게요.

#차량용품 #차청소 #차에두면편한것
```

고정 댓글: 차에 두시나요, 집에 두시나요? 저는 결국 두 대 됐어요. 지금 기준 만 구천구백 원이에요.

▸ 인스타 릴스

```
차 시트 틈 과자 부스러기, 손 안 대고 십 초에 끝났어요

아기 태우고 다니면 시트 틈은 답이 없잖아요.
손가락도 안 들어가서 그냥 포기하고 살았어요.
컵홀더에 들어가는 크기인데 버튼 하나로 끝나요.
삼 개월째 쓰는데 멀쩡하고, 남편이 자기 차에도 가져갔어요.

차 청소할 때 필요한데 그때 못 찾아요. 저장해두세요.

#살림템 #차량용품 #차청소 #자동차용품추천 #무선청소기 #차량용청소기 #시트틈청소 #아기있는차 #과자부스러기 #차에두면편한것
```
