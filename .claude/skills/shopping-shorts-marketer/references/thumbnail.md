# 썸네일·커버 문구

쇼츠와 릴스에서 "썸네일"은 두 가지로 동시에 일한다.

1. **커버 이미지** — 채널 홈·탐색 탭·릴스 그리드에서 보이는 정지 화면
2. **첫 프레임 자막** — 피드에서 자동재생될 때 0.3초에 읽히는 큰 글씨

둘은 **같은 문구**로 맞춘다. 커버와 첫 자막이 다르면 눌러 들어온 사람이 딴 영상인 줄 안다.

## 글자 규칙

- **6~12자.** 13자 넘으면 그리드 썸네일에서 안 읽힌다.
- 두 줄까지. 줄 하나에 6자 안쪽.
- **화면 위쪽 3분의 1** 에 둔다. 아래쪽은 계정명·좋아요·자막이 가린다.
- 흰 글씨 + 검정 외곽선이 가장 안전하다. 강조 한 단어만 색을 바꾼다.
- 문장부호 쓰지 않는다. 물음표 하나까지만 허용.

## 문구 공식 12개

각 6~12자. 한 편에 하나만 쓴다.

| 유형 | 형태 | 예시 |
|---|---|---|
| 숫자 먼저 | 숫자 + 결과 | 십 초에 끝 / 삼천 원 해결 |
| 손해 자극 | 모르면 + 손해 | 모르고 만 원 버림 |
| 결과 먼저 | 전후 대비 | 이게 오분 전 |
| 반전 | 예상 뒤집기 | 안 살 줄 알았는데 |
| 금지형 | 사지 말라 | 이건 사지 마세요 |
| 질문 | 되묻기 | 이거 다들 어떻게? |
| 가족 증인 | 인물 + 행동 | 남편이 가져갔어요 |
| 실패 자백 | 횟수 + 실패 | 세 번 사서 세 번 실패 |
| 의외의 용도 | 카테고리 뒤집기 | 주방템인데 차에서 |
| 계절 트리거 | 시점 + 경고 | 장마 전에 이거 |
| 대상 지정 | 누구 + 필수 | 차 있는 집 필수 |
| 오픈 루프 | 미루기 | 제일 좋은 건 끝에 |

## 3개를 뽑는 법

**결이 겹치면 고를 이유가 없다.** 세 축에서 하나씩 가져온다.

- **자극축** — 손해 자극 · 금지형 · 계절 트리거 · 숫자 먼저
- **반전축** — 반전 · 의외의 용도 · 결과 먼저 · 실패 자백
- **사람축** — 가족 증인 · 질문 · 대상 지정 · 오픈 루프

각 문구 뒤에 **노린 것**을 한 줄 붙인다. 채널 주인이 감으로 고르지 않고 이유로 고르게 하려는 것이다.

## 추천 1안 고르는 기준

| 제품이 | 추천 축 |
|---|---|
| 싸다 (만 원 아래) | 자극축 — 숫자 먼저 · 손해 자극 |
| 의외다 (용도가 안 뻔하다) | 반전축 — 의외의 용도 · 반전 |
| 흔하다 (경쟁 영상 많다) | 사람축 — 가족 증인 · 실패 자백. 남의 썸네일과 안 겹친다 |
| 계절을 탄다 | 자극축 — 계절 트리거 + 날짜 근거 |
| 비싸다 (십만 원 위) | 반전축 — 결과 먼저. 값어치를 결과로 보여준다 |

## 커버 이미지 고르는 법 (문구와 같이 안내한다)

- **손이 나온 프레임**을 고른다. 물건만 있는 컷은 상품 사진처럼 보여서 안 눌린다.
- 어질러진 before 또는 깨끗한 after 중 **대비가 큰 쪽**.
- 얼굴이 나오면 표정이 있는 프레임 (놀람·웃음). 무표정은 힘이 없다.
- 배경이 복잡하면 문구가 죽는다. 단색 벽·조리대 앞이 제일 잘 읽힌다.

## 하지 말 것

- 영상에 없는 것을 약속하기 (낚시는 이탈률로 돌아온다)
- 문구에 브랜드명부터 쓰기 (아직 아무도 관심 없다)
- "꿀템", "인생템", "레전드" 같은 닳은 말 — 클릭률이 이미 죽었고 과장이다
- 이모지로 글자 수 채우기
- 세 문구를 한 유형에서 뽑기 (선택지가 아니라 오타 교정처럼 보인다)
