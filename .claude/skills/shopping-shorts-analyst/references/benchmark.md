# 레퍼런스 영상 분해

## 조회수 요인 7개 프레임

"잘 만들어서 터졌다" 는 분석이 아니다. 아래 일곱 개로 쪼개면 **따라 할 수 있는 것과 못 하는 것**이 갈린다.

| # | 요인 | 확인하는 법 | 재현 |
|---|---|---|---|
| 1 | **훅의 정보 격차** | 0~1초에 결과·사건을 보여주고 이유를 미뤘나 | 가능 |
| 2 | **시각적 대비** | before/after, 크기 비교, 색 대비가 한 프레임에 있나 | 가능 |
| 3 | **소재의 검색 수요** | 사람들이 원래 검색하던 고민인가 (기름때·물때·틈새) | 가능 |
| 4 | **체류 설계** | 몇 초마다 화면이 바뀌나, 오픈 루프가 있나, 루프로 닫나 | 가능 |
| 5 | **참여 장치** | 양자택일 질문·논쟁 지점·저장할 정보가 있나 | 가능 |
| 6 | **타이밍** | 계절·이슈와 맞물렸나 (장마 첫 주, 김장철) | 조건부 — 시기를 맞춰야 |
| 7 | **계정·플랫폼 요인** | 구독자 규모, 유행 음원, 플랫폼 밀어주기, 운 | **불가** |

**7번을 1~6번과 섞어 적지 않는다.** 100만 조회가 대부분 7번이면 우리가 배울 게 없다는 뜻이고, 그걸 적어주는 게 정직한 분석이다.

## 체류율을 읽는 단서 (조회수 말고 이걸 본다)

- **댓글/좋아요 비율** — 좋아요 대비 댓글이 유난히 많으면 ⑤ 참여 장치가 잘 걸린 영상이다. 그 장치를 베낀다.
- **저장·공유 언급** — 캡션에 "저장" 부탁이 있는지
- **댓글 내용** — "이거 어디서 사요?" 가 많으면 제품 정보를 일부러 안 준 것이고, 그게 참여 장치다
- **같은 계정의 다른 영상 조회수** — 이 영상만 튀었으면 콘텐츠 요인, 전부 높으면 계정 요인(7번)

정보가 없으면 `확인 필요` 로 둔다. **비율을 추정해서 적지 않는다.**

## 40~60초를 20초로 압축하는 법

레퍼런스는 대개 우리보다 길다. 그대로 줄이면 말만 빨라지고 다 날아간다.

1. **비트를 센다.** 보통 6~10개 비트가 있다.
2. **남길 비트 4개를 고른다** — 훅 / 문제 / 해결 순간 / CTA. 이게 우리 20초 골격이다.
3. **버릴 것** — 인사, 자기소개, 제품 개봉 과정, 스펙 나열, 두 번째 셀링포인트, 두 번째 사용 예시.
4. **합칠 것** — "문제 + 실패 경험" 은 한 줄로 합친다. "증명 + 가족 반응" 도 한 줄.
5. **해결 순간은 줄이지 않는다.** 여기가 영상의 값이다. 20초 중 4~6초를 준다.
6. 압축 후 **공백 제외 90~105자**가 되는지 센다. → `../shopping-shorts-writer/SKILL.md`

| 레퍼런스 60초 | 우리 20초 |
|---|---|
| 인사·소개 5초 | 삭제 |
| 문제 상황 10초 | 3초 |
| 실패했던 방법들 10초 | 문제에 합쳐 1줄 |
| 제품 소개·스펙 15초 | 삭제 (숫자 하나만 남김) |
| 해결 장면 10초 | 5초 (그대로) |
| 다른 사용법 5초 | 삭제 (다음 편 소재로 적어둔다) |
| 마무리·CTA 5초 | 2.5초 (구독+태그+질문) |

## 개선안을 쓰는 규칙

`그대로 / 바꿀 것 / 버릴 것` 세 칸을 **반드시 다 채운다.** 전부 "그대로" 면 분석이 아니라 복사다.

**바꿀 것에 자주 오는 것**
- 화자 — 20대 자취생·남성 리뷰어 → 35세 육아맘 목소리로
- 전제 — 차고·건조기·벌크·카펫 → 국내 주거로
- 톤 — 쇼호스트·정보 나열 → 털털한 경험담
- 증인 — 친구·동료 → 우리 가족 고정 캐릭터
- 가격 표기 — 달러·위안 → 원, "지금 기준"
- CTA — 프로필 링크 → 제품 태그 + 구독

**버릴 것에 자주 오는 것**
- 과장 표현 (최고·1위·인생템) — 잘 나간 영상이어도 우리 규칙이 위다
- 유행 음원에 의존한 편집
- 두 번째·세 번째 셀링포인트
- 남의 제품 깎아내리는 비교

## 분석을 끝낼 때

분석만 내고 끝내지 않는다. **20초 비트 표 초안**까지 만들어 대본 담당에게 넘긴다.
초안에는 우리가 실제로 찍을 수 있는 화면만 적는다 (없는 소품·못 하는 상황을 적으면 초안이 못 쓰인다).
