# 사진에서 무엇을 읽고, 무엇을 읽지 않는가

분석의 신뢰는 여기서 결정된다. **사진에 없는 것을 있는 것처럼 적는 순간** 대본·캡션까지 거짓이 실려 나간다.

## 읽을 수 있는 것

| 읽는 것 | 어떻게 |
|---|---|
| 카테고리 | 형태와 배경으로 판단 (조리대 위 = 주방, 컵홀더 = 차량) |
| 형태 | 원통·납작·접이식·집게형·흡착식 — 형태 자체가 후킹 소재가 된다 |
| 크기 감 | 손·컵홀더·문틈 같은 **옆에 놓인 것과 비교**해서만. 숫자로 단정하지 않는다 |
| 색·마감 | 무광·유광·투명·고무 재질감 |
| 조작 방식 | 버튼 개수, 다이얼, 레버, 뚜껑 여닫는 구조 |
| 구성품 | 사진에 함께 찍힌 것만 (솔·어댑터·파우치) |
| 쓰는 자리 | 사진 배경이 곧 사용 장면인 경우가 많다 |
| 충전·전원 | 케이블 포트가 보이면 유무선 판단 가능 |

## 읽지 않는 것 (`확인 필요` 로 뺀다)

- 용량·출력·흡입력·와트·데시벨 — 사진에 표기가 찍혀 있지 않으면 모른다
- 배터리 사용 시간, 충전 시간
- 소재명 (플라스틱처럼 보인다 ≠ ABS), 인증(KC·식품용), 원산지
- 내구성·수명 ("튼튼해 보인다"는 근거가 아니다)
- 가격 — 받은 값만 쓴다. 사진에서 가격대를 추정하지 않는다
- 브랜드 — 로고가 안 보이면 적지 않는다
- 효과의 정도 ("아주 잘 빨린다"는 영상으로 증명할 일이고, 분석에서 단정할 일이 아니다)

## 형태에서 기능을 추론할 때

추론은 해도 된다. 단 **`추정` 이라고 적는다.**

| 보이는 것 | 추정 |
|---|---|
| 얇고 긴 노즐 | 좁은 틈 청소용 → 틈새가 후킹 소재 |
| 접이식 힌지 | 보관 공간이 셀링포인트 |
| 실리콘 테두리 | 흘림 방지·밀폐 |
| 흡착판·자석 | 벽·냉장고에 붙여 쓴다 → 자리 차지 안 함 |
| 눈금 표시 | 계량이 필요한 용도 |
| 손잡이 각도가 꺾임 | 손목 부담을 줄이는 설계 |

## 후킹 포인트 8개를 뽑는 순서

1. ①~④ 표(제품 한눈에·장점·구매 포인트·차별점)를 먼저 채운다. **후킹은 거기서 파생된다.**
2. 각 줄을 보고 "이걸 첫 0.3초에 어떻게 보여주지?" 를 묻는다. 보여줄 화면이 안 떠오르면 후킹 포인트가 아니다.
3. 세 축으로 배분한다.

| 축 | 개수 | 소재 |
|---|---|---|
| **자극축** | 3 | 가격·시간·손해·계절 — 숫자가 있는 것 |
| **반전축** | 3 | 의외의 용도·기존 방식과의 대비·실패 경험·결과 먼저 |
| **사람축** | 2 | 가족 증인·대상 지정·되묻는 질문 |

4. 우선순위는 **상 3 / 중 3 / 하 2.** 상을 고르는 기준:
   - 첫 화면의 **움직임이 큰가** (쏟기·잡아채기 > 놓여 있기)
   - 첫 자막이 **12자 안에** 들어가나
   - **검색어가 들어 있나** (시트 틈·기름때·물때)
   - 우리 채널에서 **찍을 수 있나** (없는 소품·못 하는 상황이면 하로)

## 확인 필요 목록 쓰는 법

비워두기만 하면 아무도 안 채운다. **누가 어디서 확인하는지**까지 적는다.

```
확인 필요
- 배터리 사용 시간 → 상품 상세페이지
- 흡입력 수치 → 상품 상세페이지 (없으면 대본에서 숫자 대신 체감으로)
- 가격 → 판매처, 영상 촬영일 기준으로 적기
```
