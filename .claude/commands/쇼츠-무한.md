---
description: 큐/inbox 에 쌓인 것들로 쇼핑쇼츠를 연속 제작한다
argument-hint: [편수 | all]
allowed-tools: Bash, Task
---

입력: `$ARGUMENTS`

`shorts-factory` 서브에이전트를 Task 로 띄워 연속 제작을 맡기세요.
전달할 내용:

- 만들 편수 (`$ARGUMENTS` 가 숫자면 그만큼, `all` 이면 큐에 남은 전부,
  비어 있으면 사용자에게 한 번 물어볼 것)
- 한 편이 실패해도 다음으로 넘어가되, 연속 3편 실패면 멈출 것
- 끝나면 표로 보고할 것

먼저 상황을 보여주고 시작하세요:

```bash
shortsforge scan
shortsforge queue list
shortsforge status
```
