입력: `$ARGUMENTS`

## 1. 상황 보기

```bash
shortsforge scan
shortsforge queue list
shortsforge status
```

## 2. 몇 편 만들지 정하기

`$ARGUMENTS` 가 숫자면 그만큼, `all` 이면 큐에 남은 전부,
비어 있으면 **사용자에게 물어보세요.** "무한"은 이름이지 실행 방식이 아닙니다.

큐가 비어 있으면 `shorts-factory` 에이전트를 먼저 띄워 다음 편 후보를 뽑고,
몇 개를 큐에 넣을지 확인한 뒤 시작하세요.

## 3. 한 번에 한 편씩

```bash
shortsforge queue take        # 대기 중 하나를 running 으로 바꾸고 이름 출력
```

꺼낸 상품에 대해 `.claude/commands/쇼츠.md` 의 절차를 그대로 수행합니다
(`shorts-product` → `shorts-keyword` → `shorts-rival` → `shorts-script`
→ `shorts-title` → `shorts-caption` → `shorts-comment`).

끝나면:

```bash
shortsforge queue mark "상품명" --status done --workspace "<작업폴더>"
# 실패했으면 --status failed
```

### 지켜야 할 것

- **동시에 돌리지 마세요.** 어느 편이 왜 실패했는지 알 수 없게 되고,
  같은 상품의 산출물이 섞입니다.
- **한 편이 실패해도 멈추지 않습니다.** `failed` 로 적고 다음 편으로.
  단 **연속 3편이 같은 이유로 실패하면 멈추고 보고하세요.**
  그건 개별 상품 문제가 아니라 프롬프트나 배선이 잘못된 겁니다.
- 영상 없이 상품명만 있는 편은 대본까지만 나옵니다. 그게 정상입니다.
  촬영 후 `shortsforge ingest` 로 영상을 붙이면 브리프가 완성됩니다.
