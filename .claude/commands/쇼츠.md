# 쇼핑쇼츠 자동 제작

입력: `$ARGUMENTS`

영상 하나를 받아 **7개 하위 프로젝트를 순서대로 돌리고**, 마지막에 캡컷으로 넘길
브리프까지 만듭니다. 각 단계가 무엇을 생각할지는 `prompts/` 안의 사용자 프롬프트에 있고,
당신은 **순서와 검증만** 책임집니다.

## 0. 입력 판별

`$ARGUMENTS` 의 첫 토큰이

- 파일 경로(`.mp4` `.mov` `.mkv` 등)이면 → 새 영상. 이렇게 투입합니다:
  ```bash
  shortsforge ingest "<영상경로>"
  ```
  출력에 찍힌 작업 폴더 이름을 이후 `<작업폴더>` 로 씁니다.
- 그 외면 → 이미 있는 작업 폴더 이름으로 봅니다.

그다음 현재 상태를 확인하세요:

```bash
shortsforge status "<작업폴더>"
```

이미 끝난 단계는 **다시 돌리지 않습니다.** 중간에 끊겼던 편을 다시 `/쇼츠` 로 부르면
멈춘 지점부터 이어집니다.

## 1. 입력 점검

`work/<작업폴더>/00_input.yaml` 을 읽으세요. 확인할 것:

- `source.images` — 제품 사진. 1·2단계(상품 분석·키워드)가 **사진을 보고** 판단합니다.
  비어 있는데 사진이 있다면 경로를 채워두세요.
- `source.reference` — 레퍼런스 영상/대본. 3단계(경쟁 분석)가 씁니다.
  비어 있으면 3단계가 키워드로 직접 찾습니다.
- `product.url`, `audience.who`, `audience.pain` — 비어 있으면 **한 번만** 물어보고,
  답이 없으면 영상·상품명에서 추론해 채운 뒤 진행하세요.

`audience` 를 비워두면 채널 기본 페르소나(35세 육아맘, `prompts/00-채널.md`)로 갑니다.
그게 정상 동작입니다. 여기서 멈춰 서서 기다리면 자동화가 아닙니다.

## 2. 7단계 순서대로 실행

`shortsforge next "<작업폴더>"` 가 다음 단계를 알려줍니다. 다음 단계가 없을 때까지 반복:

| 순서 | 에이전트 | 만드는 것 |
|---|---|---|
| 1 | `shorts-product` | 01_product.json |
| 2 | `shorts-keyword` | 02_keywords.json |
| 3 | `shorts-rival` | 03_rivals.json |
| 4 | `shorts-script` | 04_script.json |
| 5 | `shorts-title` | 05_titles.json |
| 6 | `shorts-caption` | 06_caption.json |
| 7 | `shorts-comment` | 07_comments.json |

각 단계는 **Task 로 해당 서브에이전트를 띄워서** 실행합니다.
프롬프트에는 작업 폴더 이름을 반드시 넣으세요. 예:

> `shorts-script` 에이전트에게: 작업 폴더는 `<작업폴더>` 입니다. 당신의 단계를 수행하세요.

병렬로 돌리지 마세요. 뒤 단계는 앞 단계의 산출물을 읽습니다.
단, **7단계(댓글)는 4단계가 끝나면 가능**하므로 5~6단계와 함께 묶어도 됩니다.

### 단계가 실패하면

- **프롬프트가 비어 있다** → `--skip-empty` 가 주어졌으면 그 단계를 건너뛰고 계속,
  아니면 거기서 멈추고 어느 파일을 채워야 하는지 사용자에게 알립니다.
- **검증 실패** → 같은 에이전트를 한 번 더 부르되, 무엇이 틀렸는지 전달합니다.
  두 번째도 실패하면 멈추고 보고합니다. 세 번은 부르지 않습니다.
- **입력 부족** → 무엇이 없는지 말하고 멈춥니다.

건너뛴 단계는 마지막 보고에 반드시 적으세요.

## 3. 캡컷 브리프 만들기

대본까지 나왔으면:

```bash
shortsforge brief "<작업폴더>"
shortsforge check "<작업폴더>"
```

`work/<작업폴더>/brief.yaml` 의 `footage:` 에 `00_input.yaml` 의 `source.video` 경로를
넣어주세요 (비어 있습니다). 그러면 사용자가 바로 `reelforge build` 를 돌릴 수 있습니다.


산출물 JSON 을 통째로 붙여넣지 마세요. 파일 경로면 충분합니다.
