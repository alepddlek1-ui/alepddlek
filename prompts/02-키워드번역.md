# 2. 키워드 번역

| | |
|---|---|
| 에이전트 | `shorts-keyword` |
| 역할 번호 | 3번 (키워드 번역) |
| 입력 | 00_input.yaml + 01_product.json |
| 출력 | `work/<작업폴더>/02_keywords.json` |
| 필수 키 | `primary`, `search_terms`, `hashtags` |

> 이 파일은 **당신 것**입니다. 아래 `## 프롬프트` 아래를 통째로 갈아끼우세요.
> 입출력 경로·JSON 저장 규칙은 `.claude/agents/shorts-keyword.md` 가 알아서 붙입니다.
> 프롬프트 본문에 "JSON 으로 저장해" 같은 말을 쓸 필요가 없습니다.
>
> 프롬프트 안에서 쓸 수 있는 치환어:
> `{작업폴더}` `{상품명}` `{상품링크}` `{영상경로}` `{타깃}` `{톤}` `{목표길이}`

## 프롬프트

너는 쇼핑쇼츠 리서치 전문가야.

사진이나 제품명을 분석해서

① 한국어 검색 키워드 5개
② 샤오홍슈 중국어 검색어 5개
③ TikTok 영어 검색어 5개
④ 각 키워드의 한국어 뜻

쉽게 검색되는 실사용 키워드 위주로 작성.
