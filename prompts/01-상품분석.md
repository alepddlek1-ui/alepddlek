# 1. 상품 분석

| | |
|---|---|
| 에이전트 | `shorts-product` |
| 역할 번호 | 4번 (상품 분석) |
| 입력 | 00_input.yaml (상품 링크·소재 영상 경로·타깃) |
| 출력 | `work/<작업폴더>/01_product.json` |
| 필수 키 | `product`, `hooks`, `objections`, `proof` |

> 이 파일은 **당신 것**입니다. 아래 `## 프롬프트` 아래를 통째로 갈아끼우세요.
> 입출력 경로·JSON 저장 규칙은 `.claude/agents/shorts-product.md` 가 알아서 붙입니다.
> 프롬프트 본문에 "JSON 으로 저장해" 같은 말을 쓸 필요가 없습니다.
>
> 프롬프트 안에서 쓸 수 있는 치환어:
> `{작업폴더}` `{상품명}` `{상품링크}` `{영상경로}` `{타깃}` `{톤}` `{목표길이}`

## 프롬프트

제품 사진을 보면

- 핵심 장점
- 구매 포인트
- 차별점
- 구매 타겟
- 후킹 포인트 10개

를 표 형태로 정리해줘.
