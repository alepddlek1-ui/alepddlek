8개 하위 프로젝트의 프롬프트가 파일 하나씩 들어 있습니다.
`## 프롬프트` 아래를 쓰시던 내용으로 갈아끼우면 끝입니다.

| 파일 | 역할 번호 | 에이전트 | 언제 도는가 |
|---|---|---|---|
| `00-채널.md` | — | (전부) | 모든 단계 앞에 자동으로 깔린다 |
| `01-상품분석.md` | 4 | `shorts-product` | 영상 투입 직후 첫 번째 |
| `02-키워드번역.md` | 3 | `shorts-keyword` | 상품 분석 다음 |
| `03-경쟁영상분석.md` | 5 | `shorts-rival` | 키워드가 나온 뒤 |
| `04-대본.md` | 1 | `shorts-script` | 상품 + 경쟁 분석이 끝난 뒤 |
| `05-제목.md` | 7 | `shorts-title` | 대본 다음 |
| `06-캡션썸네일.md` | 2 | `shorts-caption` | 제목 다음 |

| `08-무한생성.md` | 8 | `shorts-factory` | 다음 편 후보 130개를 뽑아 큐를 채운다 |

## 규칙 세 가지

1. **입출력은 쓰지 마세요.** "JSON 으로 저장해", "파일을 읽어" 같은 말은
   `.claude/agents/` 의 배선이 이미 붙입니다. 중복되면 오히려 충돌합니다.
2. **생각하는 방법만 쓰세요.** 무엇을 보고, 무엇을 기준으로 고르고,
   무엇을 피할지. 그게 프롬프트의 전부입니다.
3. **치환어를 쓰면 편합니다.** 프롬프트 안에 이런 걸 쓰면 실행할 때 실제 값으로 바뀝니다:

   | 치환어 | 무엇 |
   |---|---|
   | `{상품명}` `{상품링크}` `{카테고리}` `{가격}` | 상품 |
   | `{영상경로}` `{영상길이}` `{사진}` `{레퍼런스}` | 소재 |
   | `{타깃}` `{불편}` `{톤}` `{목표길이}` | 이번 편 설정 |
   | `{채널}` | `00-채널.md` 내용 (안 써도 앞에 자동으로 깔립니다) |
   | `{작업폴더}` | `work/<이름>` 경로 |

   JSON 예시의 중괄호(`{"hook": ...}`)는 건드리지 않으니 그대로 써도 됩니다.

## 채웠는지 확인

`/쇼츠` 를 인자 없이 치면 빈 슬롯까지 같이 알려줍니다.

빈 슬롯이 있으면 그 단계에서 멈춥니다. 급하면 `/쇼츠 <이름> --skip-empty` 로
빈 단계를 건너뛸 수 있습니다.

## 개수를 바꿔도 됩니다

"후킹 포인트 10개" 를 15개로 바꾸셔도 아무것도 안 고쳐도 됩니다.
검증은 개수가 모자라면 **경고만** 하고 그냥 넘어갑니다 (`!` 표시).
작업이 멈추는 건 결과 자체가 비었을 때뿐입니다.
